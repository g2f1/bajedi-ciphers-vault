This section summarizes the terminology and abbreviations used throughout this study.

-  **Cryptosystem** : In cryptography it represent the set of cryptographic algoritms, plaintext and ciphertext. Mathimatically cryptosystem or encryption scheme is defined as the tuple $(\mathcal{P}, \mathcal{C}, \mathcal{K}, \mathcal{E}, \mathcal{D})$ where $\mathcal {P}$ is a set called the "plaintext space". Its elements are called plaintexts, $\mathcal {C}$ is a set called the "ciphertext space". Its elements are called ciphertexts, $\mathcal {K}$ is a set called the "key space". $\mathcal{K}$: key space (set of all keys), $\mathcal{E} = \{E_k \mid k \in \mathcal{K}\}$: set of encryption functions where $E_k : \mathcal{P} \rightarrow \mathcal{C}$, $\mathcal{D} = \{D_k \mid k \in \mathcal{K}\}$: set of decryption functions where $D_k : \mathcal{C} \rightarrow \mathcal{P}$.
